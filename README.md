## Engineering Standards I Am Applying

For each flagship project, I am working toward:

- Reproducible setup and execution from a clean clone.
- Unit, integration, negative, and failure-path tests.
- Least-privilege permissions and secure configuration defaults.
- Threat models, architecture decisions, and documented limitations.
- CI evidence that shows both successful controls and intentionally blocked insecure cases.
- Measured results with a stated test corpus and methodology.
